## 定制改动点

### 推荐 / 内容质量
- 冷启动直接拉取一页推荐；不保留启动快照缓存，原「启动时自动刷新首页」开关一并移除。
- 内容详情落盘缓存：已展示过的详情写入本地，冷启动优先读盘，减少重复请求；同时提高信息流详情抓取的 HTTP 并发。
- 统一最低赞数阈值做质量过滤，隐藏模式覆盖混合、安卓（手机版）与 Web 三种推荐来源。
- 隐藏模式下已过滤卡片不再被写回；作者字段缺失时不再误杀整条内容。

### 屏蔽 / 隐藏
- 隐藏设置项支持除「系统与更新」外的全部入口，且不再把开发者选项算进去。
- 屏蔽视频 / 想法归入屏蔽功能组，紧随盐选之后；隐藏入口后不再显示「已隐藏」占位行。
- 想法不并入统一赞数阈值，避免整条想法流被误杀。

### 搜索
- 支持删除单条搜索历史。
- 默认按「最多赞同」排序，并隐藏与搜索场景无关的质量过滤项。

### 设置项开关（外观等设置页）

新增：

| 开关 | 作用 |
|---|---|
| 显示划线段评 | 带段评的句子是否显示虚线下划线并可点开段评 |
| 记忆阅读位置 | 重新打开文章 / 回答时回到上次读到的位置，记忆条数可设（默认 1 条） |
| 标题始终收起 | 顶部大标题固定为一行收起态，滚动不再展开 |
| 点击推荐卡片答主进入个人主页 | 主页推荐卡片里答主头像 / 昵称点击是否进个人主页（默认开） |
| 主页发布按钮 | 主页右下角的 ＋ 创作按钮是否显示（默认开） |

刷新按钮沿用上游已有的「显示刷新悬浮按钮」，未再另加开关。

### 功能裁剪
- 电纸书翻页整套：音量键翻页、翻页悬浮按钮、翻页距离、翻页位置线、内容结束标记、翻页切换回答，相关设置分组一并移除。
- 回答页「跳转下一个回答」悬浮按钮及其开关。
- 问题页标题自动吸附逻辑（标题改为固定显示，不再随滚动出现 / 消失）。
- 系统与更新页的 GitHub Token 输入框。

### 其他调整
- 回答页去掉顶栏吸附与切换回弹突跳，改为连续跟手。
- 列表预取在列表为空时不再抢先发请求，避免和启动刷新叠成两次请求。
- 设置项描述统一口径（句末标点、数字两侧空格、去掉口语化表述），并补齐设置搜索索引。

### 登录 / 构建
- 移除首次打开声明，登录只保留手机号。
- 改用独立包名，解决与官方版签名冲突导致装不上的问题。
- 不再跟踪本地签名密钥，忽略整个 `.local-signing` 目录。
