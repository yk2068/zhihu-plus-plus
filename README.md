## 定制改动点

### 推荐 / 内容质量

- 统一最低赞数阈值做质量过滤，隐藏模式覆盖混合、安卓（手机版）与 Web 三种推荐来源。
- 隐藏模式下已过滤卡片不再被写回。

### 屏蔽 / 隐藏

- 隐藏设置项支持除「系统与更新」外的全部入口。
- 屏蔽视频 / 想法归入屏蔽功能组。

### 搜索

- 支持删除单条搜索历史。
- 默认按「最多赞同」排序，并隐藏与搜索场景无关的质量过滤项。

### 设置项开关（外观等设置页）

新增：

| 开关                         | 作用                                                               |
| ---------------------------- | ------------------------------------------------------------------ |
| 显示划线段评                 | 带段评的句子是否显示虚线下划线并可点开段评                         |
| 记忆阅读位置                 | 重新打开文章 / 回答时回到上次读到的位置，记忆条数可设（默认 1 条） |
| 标题始终收起                 | 顶部大标题固定为一行收起态，滚动不再展开                           |
| 点击推荐卡片答主进入个人主页 | 主页推荐卡片里答主头像 / 昵称点击是否进个人主页（默认开）          |
| 主页发布按钮                 | 主页右下角的 ＋ 创作按钮是否显示（默认开）                         |

### 功能裁剪

- 电纸书翻页整套：音量键翻页、翻页悬浮按钮、翻页距离、翻页位置线、内容结束标记、翻页切换回答，相关设置分组一并移除。
- 回答页「跳转下一个回答」悬浮按钮及其开关。
- 系统与更新页的 GitHub Token 输入框。

### 登录

- 移除首次打开声明，登录只保留手机号。
