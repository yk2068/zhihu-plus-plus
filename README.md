## 定制改动点

### 推荐 / 内容质量
- 推荐模式与启动快照逻辑调整，启动先用缓存填屏。
- 内容详情持久化到磁盘，下次启动先读缓存，并提高信息流详情的 HTTP 并发以加速加载。
- 统一最低赞数阈值做质量过滤，隐藏模式支持混合/安卓推荐与手机版推荐。
- 修复隐藏模式下已过滤卡片被写回、作者字段缺失时误杀等问题。

### 屏蔽 / 隐藏
- 隐藏设置项支持除「系统与更新」外的全部入口，且不再包含开发者选项。
- 屏蔽视频/想法归入屏蔽功能组，紧随盐选之后；隐藏入口后不再显示「已隐藏」占位行。
- 想法不再并入统一赞数阈值，避免整条想法流被误杀。

### 搜索
- 支持删除单条搜索历史。
- 搜索默认按 MostVoted 排序，并隐藏质量过滤项。

### 外观 / 交互
- 新增「显示划线段评」开关，可整体关闭段评划线。
- 新增「记忆阅读位置」开关：重新打开文章/回答时回到上次读到的位置，记忆条数可设（默认 1 条）。
- 回答页去掉顶栏吸附与切换回弹突跳，改为连续跟手。
- 系统与更新页裁剪 GitHub Token 输入框。

### 登录 / 构建
- 移除首次打开声明，登录只保留手机号。
- 改用独立包名，解决与官方版签名冲突导致装不上的问题。
- 不再跟踪本地签名密钥，忽略整个 `.local-signing` 目录。
